# NitroSense Predator Theme

**A Predator-inspired visual theme for Acer NitroSense.**

This project aims to bring the visual style of Acer PredatorSense to Acer NitroSense, creating a different interface while preserving the original purpose of the application.

## About the Project

NitroSense Predator Theme is a personal customization project created by me for the Acer Nitro V15 ANV15-52.

The project modifies selected interface elements to adopt a Predator-inspired color palette, including blue and green accents, interface graphics, animation colors, and certain default visual settings.

The goal is to explore the customization possibilities of NitroSense and give the application a different visual identity.

## Features

- Predator-inspired blue and green color palette.
- Modified interface graphics and visual elements.
- Customized animation colors.
- Adjusted default colors for selected interface components.
- Customization focused on the NitroSense interface.

## Compatibility

- **Tested device:** Acer Nitro V15 ANV15-52.
- **Target software version:** NitroSense 5.1.392 for the original theme modification.
- **Status:** Experimental.

Compatibility with other Acer Nitro devices, other NitroSense versions, and future software updates has not been confirmed.

Installation over an existing NitroSense installation is still under investigation.
